# Orbital Semantic Grammar v0.1 — candidate

Status: **CANDIDATE / CHYBA**. No canon promotion. No physical binding.

## Hierarchy

The candidate inserts one explicit level between atomic written carrier and
radical/root:

```
KAKU -> chi(+/-) -> RADICAL -> CONCEPT -> SENTENCE
```

- **KAKU**: atomic written carrier with a dimensionless structural weight.
- **chi(+/-)**: local orbital cell; plus/minus are complex-conjugate
  phase/counterphase representations of the same carrier.
- **RADICAL**: ordered composition of orbital cells.
- **CONCEPT**: radical plus morphology/realization phase.
- **SENTENCE**: order-sensitive concept field plus typed relation field, combined
  by a moire-like interference operator.

The kana phase/counterphase analogy motivated the dual representation but is not
a linguistic claim about Japanese. The existing Japanese freeze remains intact.

## Hebrew candidate

Hebrew already exists in LingoPhysics under `family:semitic` with
`root_pattern_analyzer`. v0.1 adds a research-candidate `language:he:standard`
profile and does not enable it in default probes.

Ordinary Hebrew gematria may be retained as a numerical seed for KAKU structural
weights, but the implementation explicitly separates:

```
numeric value != lexical meaning != physical mass
```

Final letter forms normalize to their base-letter values for this seed.

An unwritten/underdetermined vowel is represented by a uniform latent phase
ensemble. Its complex expectation is approximately zero while its second moment
and entropy remain non-zero. This is a computational "zero mean, non-zero
potential" representation; it is not a zeta-function theorem.

## Lambda and phase

`communication_lambda in [0,1]` is a bounded computational coupling/availability
coefficient. It is not a cosmological constant.

Vocalization/morphology contributes a semantic phase. The Aharonov-Bohm analogy
is limited to phase/holonomy structure. The module does not claim a physical
electromagnetic potential.

## Sentence decomposition

The sentence state preserves three separable channels:

```
bag      = which concepts are present
lexical  = concept order
syntax   = typed relational edges
```

The final state is a moire-like combination of lexical and syntax fields.
Therefore token-set equality does not imply sentence-state equality.
